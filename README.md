## T-League - T20 Cricket Match in CLI 

T-League is a terminal based cricket match system. It allows to play for 2 overs. 

### Features 

The CLI is almost realistic in terms of real-world cricket match dashboard. The player can feel the dynamic and engaging dashboard with fullfledge cricket centric 
user-experience in terminal. The CLI project shows the some of the following important data while playing the data: 

- Run of both Batter
- Current Batter 
- Strike Rate
- Current Over
- Number of Ball Left
- Run Given by the Bowler
- Run Scored by the Batter
- And many more.

### How To Run 
- Please clone the repositoy and run `python main.py`.

- Follow the instructions

- RUN: 1 to 6

- Wicket: `W`

- WideBacll: `Wrun`
    - Example: `W2` - `W` indicates `Wide Ball`, and the attached `INT` value of 2 indicates the run obtained in this wide ball.
    - NOTE: A singe `W` indicates `Wicket`. 

 - NoBall: `Nrun`
     - Example: `N3` - `N` indicates the `No Ball`, and the attched `INT` value of 3 indicates the run obtained in this no ball.
